## ✨ ¿Qué es ALEX BOT?

> Tu asistente de WhatsApp que hace de todo sin salir del chat 🚀

Conectado a la **ALEX SCRAPER API**, ALEX BOT descarga, crea, juega y te informa.  
Arquitectura **100% modular**: cada comando es un archivo en `/commands`. Agregar uno nuevo = 30 segundos.

**Hecho para**: Grupos, canales, uso personal y para creadores como tú 💜
